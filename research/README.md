# Research source corpus

The Markdown files in `research/articles/` are the four source articles supplied with the project. They are preserved as historical design context and mapped from their original uploaded filenames through `MIGRATION_MANIFEST.json`.

1. `01_llm_trader_top_traders.md` — LLM trader with embedded top-trader philosophy and the transition away from forced binary UP/DOWN decisions.
2. `02_continual_llm_adaptation.md` — continual adaptation, memory weighting, retraining triggers, and regime shifts.
3. `03_rl_llm_quantum_seal.md` — RL agent, LLM, quantum encoding, and SEAL-style adaptation.
4. `04_autonomous_llm_seal_forward.md` — autonomous LLM trading agent, SEAL framing, and forward-testing workflow.

These articles document the evolution of the project. When a historical claim conflicts with the approved Sovereign Trader design, the design specification in `docs/superpowers/specs/` is authoritative for future implementation.
